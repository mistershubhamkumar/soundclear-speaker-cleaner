# soundclear-speaker-cleaner
Mobile-friendly speaker cleaner web app for GitHub Pages.

This repository contains a static web app designed to run on GitHub Pages.

## Local preview
Open `index.html` in a browser, or serve the folder with a simple local web server:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000

## GitHub Pages
This project is ready to be published from the `main` branch root.
